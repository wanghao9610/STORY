# 润色学位论文

首先完整阅读 `docs/mds/story-workflow/writing-workflow-conventions.md`。解析一个章节目标，或明确确认全文处理；读取风格、符号、总叙事和相关章节简报。

改进句式、段落流动、路标、术语、缩写首次出现和跨章节一致性。全文模式重点识别论文式引言重复、相关工作重复、符号冲突和缺失过渡。

不得改变任何数字、citekey、`\todo`、论断强度、贡献归属或技术含义；这些问题只报告并路由。保持一句一行。

编辑后构建，持久待办写入 `tasks/`。`style` 模式只更新 `notes/style.md`。
