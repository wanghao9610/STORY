# 构建博士答辩

首先完整阅读 `docs/mds/story-workflow/writing-workflow-conventions.md`。解析 `pre-defense` 或 `defense` 里程碑；时长、必需部分、模板、比例与提交规则来自已确认的 `milestone.yml` 或作者。

在 `materials/` 创建答辩计划，说明受众、中心信息、时间预算、贡献顺序、主要页面证据、过渡、局限和结束论断。演示文稿保留可编辑源；复用论文图时保证放映条件下可读。

每项数字或比较性页面论断都要对应 verified 论断和已登记证据。附录/问题库覆盖方法、假设、消融、局限、作者归属和未来工作。检查时长、字号、对比度、来源可见性及与正文一致性。

不得编造委员会要求或重新设计证据；未解决答辩风险要显式报告。
