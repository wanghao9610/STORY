# 学位里程碑

**语言：** [English](README.md) | 简体中文

> 本文件是中文对照版。里程碑目录、事实和状态仍按 [`README.md`](README.md) 说明，在正式记录中使用英文结构键和值。

每次持久化的审查或提交事件建立一个目录，例如：

```text
milestones/
└── defense_2027/
    ├── milestone.yml
    ├── feedback/          # 收到的文件；绝不原地修改
    ├── response/          # 逐点记录与处理决定
    ├── materials/         # 答辩或审查交付物
    └── RECORD_2027-05-20.md
```

建议的 `kind` 值包括 `proposal`、`annual-review`、`pre-defense`、`defense`、`corrections` 和 `deposit`。日期、规则和结果都必须由用户确认。
