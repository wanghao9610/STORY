# 进行模拟博士论文审查

首先完整阅读 `docs/mds/story-workflow/writing-workflow-conventions.md`。解析里程碑并先构建论文；学校提供的审查标准只使用已确认版本，否则明确标注为通用模拟标准。

评估中心论点是否清晰贯穿、贡献是否原创重要且证据和归属准确、研究章节是否形成一部论文、方法与可复现性、文献掌握与定位、跨研究综合与局限、表达质量以及可能的口试问题。

写入 `milestones/<slug>/feedback/SIM_EXAM_<date>.md`，包含总体结论、重大与次要问题、必须澄清项、受攻击的论断/贡献 ID 和答辩问题库。本 skill 不修改正文或论断表。
