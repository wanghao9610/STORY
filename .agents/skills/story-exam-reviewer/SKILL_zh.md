# 进行模拟博士论文审查

首先完整阅读 `docs/mds/story-workflow/writing-workflow-conventions.md`。解析当前或指定的里程碑，并在审查前构建学位论文。如果学校提供了评审标准，只使用已确认的副本；否则把通用标准明确标为模拟标准。

评估：

- 中心论点是否清晰且贯穿全文；
- 贡献是否原创、重要、有证据支持且归属正确；
- 研究章节是否形成一部完整学位论文，而不是装订在一起的论文合集；
- 方法是否可靠以及研究能否复现；
- 对文献的掌握和定位是否准确；
- 跨研究综合、局限与泛化边界；
- 表达质量和可能的口试问题。

写入 `milestones/<slug>/feedback/SIM_EXAM_<date>.md`，包含总体结论、重大问题、次要问题、必须澄清项、被质疑的论断/贡献 ID 和答辩问题库。本 skill 不修改正文或论断记录表。
