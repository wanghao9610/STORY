# 设计一个可追溯图

首先完整阅读 `docs/mds/story-workflow/writing-workflow-conventions.md`。从 `notes/outline.md` 解析一个图。若是新图，先确认其用途、所属章节和论断 ID，再按规范 §3 的提纲状态契约将其记为 `planned`。

选用能清楚呈现目标关系的最简视觉形式。可编辑源文件放在 `manus/figs/srcs/`，用于发表的渲染产物放在 `manus/figs/`，并在可编辑源文件内或旁边保存一份可用 grep 检索的来源映射。

每个数据图元、数字标签和图注中的比较性论断，都必须映射到本轮读取的已登记证据。生成或装饰性像素绝不是证据。保证图的可访问性：字体清晰可读，区分不只依赖颜色，对比度合适，图注信息充分。

更新提纲与关联论断，将渲染图引入其所属章节，然后构建并 lint。不得把唯一的可编辑源文件压平掉。
