# Copy-edit the dissertation

Read `docs/mds/story-workflow/writing-workflow-conventions.md` first. Resolve a chapter target or explicitly confirm a whole-dissertation pass. Load `notes/style.md` where present, plus `notes/notation.md`, `notes/story.md`, and the relevant outline briefs. A missing style profile is not a blocker for ordinary copy-editing; missing narrative, notation, or outline metadata routes to its owning creator.

Improve sentence structure, paragraph flow, signposting, terminology, acronym introduction, and cross-chapter consistency. For a whole-dissertation pass, identify repeated paper-style introductions, duplicated related work, conflicting notation, and missing transitions.

Do not change any number, citation key, `\todo`, claim strength, contribution attribution, or technical meaning. Report those issues and route them to the owning skill. Preserve one sentence per source line.

Build after editing and write any durable follow-up as a checkbox under `tasks/`. A `style` mode may update `notes/style.md` without editing prose. In that mode, create the file when absent with fields for manuscript language, voice, terminology rules, acronym policy, chapter-opening pattern, cross-chapter signposting, and citation style; create `notes/style.zh-CN.md` in the same change and never overwrite an existing profile with the scaffold.
