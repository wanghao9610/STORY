# 润色学位论文

首先完整阅读 `docs/mds/story-workflow/writing-workflow-conventions.md`。解析一个章节目标，或明确确认执行全文处理。读取存在的 `notes/style.md`，以及 `notes/notation.md`、`notes/story.md` 和相关提纲简报。普通润色不因风格档案缺失而阻塞；总叙事、符号表或提纲元数据缺失时，路由给负责创建它的 skill。

改进句式、段落流动、路标、术语、缩写首次出现和跨章节一致性。全文模式重点识别论文式引言重复、相关工作重复、符号冲突和缺失过渡。

不得改变任何数字、引用键、`\todo`、论断强度、贡献归属或技术含义；报告这些问题并将其路由给负责的 skill。保持源文件一句一行。

编辑后构建，并把需要持续跟进的工作写成 `tasks/` 下的复选框。`style` 模式可以更新 `notes/style.md` 而不编辑正文。该模式下，文件缺失时创建，并包含论文语言、声音、术语规则、缩写策略、章节开篇模式、跨章路标和引用风格字段。论文语言使用 `en | zh`；其余字段留空或填写作者确认的自由文本，只有某项规则确认不存在时才使用 `none`。在同一次修改中创建 `notes/style.zh-CN.md`，且绝不能用骨架覆盖已有档案。
