# Degree and deposit requirements

**Language:** English | [简体中文](requirements.zh-CN.md)

Record each item from an official, author-confirmed source, and keep the source URL or supplied file path beside the requirement. When an item does not apply to the selected degree level, record that confirmed fact and check the row as resolved instead of leaving an ambiguous open gate.

## Filling guide

- Checkbox: `[ ]` means unresolved; `[x]` means the requirement or its confirmed non-applicability is fully resolved. Do not check a row merely because no rule was found.
- `applicability`: empty until confirmed, then `applies` or `not-applicable` only.
- `source`: empty until verified, then a stable `https://` URL or repository-relative path to the supplied official record.
- `notes`: empty or concise free text containing the exact limit, choice, exception, approval, or location of a longer record. Never put an unsupported institutional fact here.
- Canonical row form: `- [ ] Requirement — applicability: — source: — notes:`.

- [ ] Degree level and official degree name confirmed — applicability: — source: — notes:
