# 学位与归档要求

**语言：** [English](requirements.md) | 简体中文

> 本文件是中文对照版。权威、可写的要求检查表仍是 [`requirements.md`](requirements.md)；确认状态和来源只在英文原文件中维护。

每项要求都必须来自经作者确认的正式材料，并在要求旁保留来源 URL 或用户提供的文件路径。某项不适用于所选学位层级时，应记录这一经确认的事实并将其勾选为已解决，不要留下含义不明的开放关口。

## 填写说明

- 复选框：`[ ]` 表示尚未解决；`[x]` 表示该要求或其经确认的不适用状态已经完全解决。不能仅因没有找到规定就勾选。
- `适用性`：确认前留空；确认后只能填写 `applies` 或 `not-applicable`。
- `来源`：核验前留空；核验后填写稳定的 `https://` URL，或指向已提供正式材料的仓库相对路径。
- `备注`：留空，或填写准确限制、选项、例外、批准情况或较长记录的位置。不得在此写入无依据的学校事实。
- 规范行格式：`- [ ] 要求——适用性：——来源：——备注：`。

- [ ] 学位层级和正式学位名称已确认——适用性：——来源：——备注：
- [ ] 标题页措辞已确认——适用性：——来源：——备注：
- [ ] 必需的前置部分及其顺序已确认——适用性：——来源：——备注：
- [ ] 纸张尺寸、页边距、字体和行距已确认——适用性：——来源：——备注：
- [ ] 摘要和关键词限制已确认——适用性：——来源：——备注：
- [ ] 引用和参考文献规则已确认——适用性：——来源：——备注：
- [ ] 已发表内容复用和许可规则已确认——适用性：——来源：——备注：
- [ ] 作者身份和贡献声明要求已确认——适用性：——来源：——备注：
- [ ] 无障碍要求已确认——适用性：——来源：——备注：
- [ ] 文件格式、命名和大小要求已确认——适用性：——来源：——备注：
- [ ] 提交门户和截止日期已确认——适用性：——来源：——备注：
- [ ] 延迟公开和许可选择已确认——适用性：——来源：——备注：
