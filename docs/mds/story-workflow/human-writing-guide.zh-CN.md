# 受证据约束的清晰学位论文写作

**语言：** [English](human-writing-guide.md) | 简体中文

本指南把常见公式化写作模式的复核规则应用于硕士和博士学位论文正文。
目标是用作者自己的声音写出清楚、自然的学术文字，而不是判断作者身份或规避检测器。
证据、引用、归属和论断仍以[写作工作流规范](writing-workflow-conventions.zh-CN.md)为准。

## 1. 保持内容与出处不变

风格编辑可以重组表达，但不得改变学位论文能够辩护的内容。

- 修改受相应记录控制的正文前，先读取相关章节简报、论文主线、提纲、论断、贡献与发表记录、映射的 `mates/` 证据、阅读笔记、符号表、风格档案，以及已确认的学位或学校正式措辞。
  记录冲突时应报告冲突，不能在正文中自行调和。
- 保留事实、数字、日期、引文、引用、来源锚点、论断与贡献 ID 及其强度、技术区别、未确定性、归属、比较集合、适用条件和必要限定语。
- 题名、名称、代码、符号、LaTeX、学校正式措辞和来源专用术语均视为受保护文本，除非任务明确拥有它们。
- 具体细节只能来自已登记证据或作者。
  缺少支持时，继续用 `\todo{...}` 或负责的工作流显式呈现缺口；不得补入看似合理的数值、来源、事实或学位要求。
- 如果修改会新增、删除、移动、削弱或加强论断，它就不再只是风格编辑。
  应交给负责的工作流，并在同一变更中更新 `notes/claims.md`。
- 复用论文文本仍须服从学位论文主线、术语、归属和复用记录。
  论文是证据，不是学位论文的默认措辞或声音。

## 2. 贴合作者与学位论文

有经作者确认的样本时遵循样本。
匹配其中可观察的用词、句子推进、标点、过渡、限定方式、第一人称用法和有意重复，但不得借用句子，也不得添加事实、观点、幽默或刻意的混乱。
没有样本时，使用克制、直接的学术表达。

- 按 `degree/profile.tex` 记录的语言撰写手稿正文。
- 先写实质内容，使用规范术语和简单动词。
  主体或贡献者影响解释或归属时，应明确指出。
- 围绕映射的“论断—证据—推论”顺序、章节简报和 `notes/story.md` 中的论文总论点组织段落。
- 把证据连接到局部推论，再把推论连接到研究问题或贡献，不得超出证据支持范围。
- 让句长和段落结构服从推理。
  以有支持的发现、限制、综合结论或有效过渡收尾，不写空泛乐观结论。
- 全文处理时复核重复的开篇、文献总结、方法回顾、贡献陈述、局限和章节结尾，同时保留有意建立的跨章一致性。
- 只有作者确认的声音和学术语境都需要时才增加个性。
  不得制造人格，也不得暗示合作成果由作者独立完成。

## 3. 按模式组合复核

以下内容是编辑信号，不是禁用形式，也不能证明文本由 AI 生成。
多个信号集中出现、同一模板反复出现，或某个模式引入无依据论断时，才按段落改写。

| 复核对象 | 改写方向 |
| --- | --- |
| 夸大意义、宣传话术、罗列名望、无依据的最高级或套路化乐观结尾 | 确切结果及其有支持的影响。 |
| 模糊归因、知识限制声明或看似合理的猜测 | 明确且已核验的来源与可检查命题；否则显式保留缺口或删除。 |
| 空洞分析尾巴、抽象行动链、隐藏主体或限定语堆叠 | 直接的“事实—推论”关系、必要时明确主体，并只保留证据要求的限定。 |
| 反复使用“不仅……而且……”、强凑三项或虚假范围、虚设异议或备选方案、刻意坦诚、金句或假装揭示“深层本质” | 删除起草脚手架，只写真实关系、约束或选择。 |
| 套路化路标、重复标题、填充语、问候、赞美、道歉、预告、继续服务邀请或通用结尾 | 直接写内容，只保留读者需要的导航。 |
| 术语轮换、套话密集、重复句首、均匀节奏、戏剧化碎句、过多破折号、装饰性强调、标签堆叠的列表或表情符号 | 保持名称稳定；句法、节奏和格式只在有明确功能时变化。 |

不要孤立禁用某个词、连接词、被动句、第一人称、长句、列表或破折号。
一种形式表达真实关系、保留技术含义或符合作者习惯时，应当保留。
引文、题名、符号、数据和字面字段即使命中观察模式，也不得仅为消除模式而改写。
`lint.sh` 使用 `chatbot-residue`、`inflated-significance`、`vague-attribution`、`formulaic-contrast`、`stock-signposting`、`shallow-analysis`、`generic-outlook`、`manufactured-depth` 和 `stock-diction` 等标签报告已配置模式。
这些警告只定位需要复核的段落；扫描干净仅表示没有触发已配置模式。
不得给出数值化“人类分数”。

## 4. 改写并验证

1. 确定修改目标、章节简报、手稿语言，以及控制相应段落的已确认学位背景。
2. 读取控制相应段落的记录，标出全部受保护的字面内容和语义内容。
3. 梳理“论断—证据—推论”顺序及其在论文主线中的作用，并按段落判断模式组合。
4. 围绕实质内容整体改写，不逐个替换观察词。
5. 将修订版与原文、台账、证据、阅读笔记、符号表、贡献与发表记录和风格档案对照。
   恢复遗漏的限定语、追溯关系或归属，并删除新增或被加强的论断。
6. 保持源文件一句一行；修改 `manus/` 后运行 `bash execs/run.sh` 和 `bash execs/scpts/lint.sh`。

如果更顺的写法需要尚未导入的证据、不同的论断或学位要求、没有支持的被引事实、新的规范术语、改变归属或删除必要限定语，应保留原文并报告问题。
只有论断守恒与可追溯性通过、归属准确、术语稳定，而且相应段落仍服务于章节和论文总论点，修订才可交付。
