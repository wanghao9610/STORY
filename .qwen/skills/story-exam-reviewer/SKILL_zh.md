# 进行适合学位层级的模拟审查

先阅读 `docs/mds/story-workflow/writing-workflow-conventions.md` 和 `docs/mds/story-workflow/human-writing-guide.md`。解析学位层级和适用于该层级的当前或指定里程碑，然后在审查前构建论文。学校若提供了评审标准，只使用已确认的副本；否则，把与层级相符的通用标准明确标注为模拟标准。

评估：

- 中心论点是否清晰且贯穿全文；
- 贡献是否满足已确认层级对范围、重要性、证据和作者归属的要求；
- 博士模式下，论文是否建立了规定的原创贡献和跨研究综合；
- 硕士模式下，范围明确的贡献是否体现规定的专业掌握与研究能力，而不以发表论文、多项研究或领域级原创性为前提；
- 复用发表论文时，研究章节是否形成一部完整学位论文，而不是装订在一起的论文合集；
- 方法是否可靠，研究能否复现；
- 论文是否展现了对文献的掌握，并将所做工作准确定位；
- 综合、局限与泛化边界是否与学位层级相称；
- 表达是否经得起检验：检查没有支持的意义拔高、模糊归因、重复的章节或段落模板、通用展望措辞、术语轮换和聊天机器人残留，这些均按模式组合判断，而非 AI 创作的证明；
- 口试中可能出现哪些问题。

写入 `milestones/<slug>/simulations/SIM_EXAM_<date>.md`，包含总体结论、重大问题、次要问题、必须澄清项、被质疑的论断/贡献 ID 和答辩问题库；里程碑目录尚不存在时，按公约 §6 依据作者确认的事实创建。`feedback/` 只存放收到的意见——模拟审查绝不写入该目录。本 skill 绝不改动正文或论断记录表。
