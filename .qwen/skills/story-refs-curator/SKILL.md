# Curate references and reading notes

**Shared conventions.** Read `docs/mds/story-workflow/writing-workflow-conventions.md` in full before acting. Read `.env` once for the `STORY_LANG`, `INVOLVE`, and `STORY_MAIN` values this run needs, and reuse them. Resolve the language of replies and new Markdown under conventions §7: an explicit author request first, then a valid `STORY_LANG`, then the dialogue language, read from the author's latest own prose and never from a bare command or the English this run loads, or the invocation language when there is no user turn. Manuscript prose follows `degree/profile.tex`, and an existing file keeps its language. A clear instruction may select the target and scope and authorize the corresponding action within this skill's documented paths, and work already authorized in this run is not asked for again; it never replaces a confirmation point or an `AGENTS.md` §1 ask-first choice (conventions §7).

Targets: works, each named by DOI, arXiv ID, stable URL, or quoted exact title; a chapter, whose unsupported literature assertions the run collects and answers with proposed candidates; or `reconcile`, which indexes the existing bibliography. Propose discovered candidates before adding any (at `low`, list them and add none); a run with no accepted candidate writes nothing. Files are created on first use (conventions §1).

1. For each work, fetch an authoritative record in this run and transcribe its fields into `manus/bibs/reference.bib`, never reconstructing metadata from memory, with a `% src:` line naming the fetched record (conventions §2). Whenever `reference.bib` holds an entry and the active entry point does not load it, uncomment or add its `\bibliographystyle` and `\bibliography` lines (conventions §7, Ownership).
2. Write `notes/refs/<key>.md` with the research question, method, evidence, findings, limitations, and short citable facts actually checked.
3. In `notes/refs/refs_index.md` (`Bibkey | Work | Reading note | Used in chapters | Verification status`), set `Verification status` as conventions §3 (Who sets each status) directs, routing the assertions that cite a newly `stale` key to `story-cite-auditor`, and recompute `Used in chapters` from the `\cite` keys in `manus/` whenever the run writes the index.
4. `reconcile` gives every bibliography entry without a row an `unverified` row, then verifies entries in batches the author picks (at `low`, by chapter in outline order), never dropping or renaming an entry the manuscript cites.

Distinguish bibliographic verification from endorsement, and primary sources from surveys. Rename an already-cited key, or merge a duplicate, only after listing its `\cite` sites and getting the author's confirmation (at `low`, keep the key and report the proposed rename); then rewrite its citation-command key arguments in `manus/` (conventions §7), index row, and reading note, reporting each old→new key with its sites. Never patch prose: route an unsupported manuscript assertion to `story-cite-auditor` for audit, or to `story-chap-drafter` once the author has confirmed the rewrite. Tick any `tasks/` line this change resolves (conventions §6); after a `manus/` change, build and lint (conventions §8).
